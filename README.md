# $bog_brelok

Где сделать отверстие под петельку, чтобы брелок висел ровно.

https://b-on-g.github.io/brelok/

Загрузите картинку брелка: PNG без фона или фото на однотонном фоне. Сервис найдёт центр тяжести (толщина считается одинаковой) и поставит отверстие на вертикаль над ним с заданным отступом от края. Размер брелка задаётся по большей стороне в сантиметрах, отступ и диаметр отверстия в миллиметрах.

Клик по схеме примеряет свою точку: справа видно, как брелок повиснет, а в тексте указан перекос в градусах.

- `pivot/` расчёт: маска брелка по фону, центр тяжести, точка отверстия, перекос
- `app/` приложение
